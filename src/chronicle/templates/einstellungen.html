Discord

Der Bot-Token öffnet den Diktat-Kanal #diktat: eine Sprachnachricht dort landet in derselben Warteschlange wie ein Upload, eine Textnachricht wird zur Notiz der zuletzt angelegten Sitzung. Wer im Kanal schreiben darf, darf diktieren — die Rechte vergibt Discord. Ohne Token bleibt der Kanal zu; eine Gruppe, die nur vor Ort spielt, braucht ihn nicht.

{% if not bot_token_gesetzt %}

Noch kein Bot? So entsteht er, einmalig, in etwa fünf Minuten:

  1. Im Discord Developer Portal eine New Application anlegen, dann links Bot öffnen und den Token erzeugen — der gehört ins Feld unten und sonst nirgendwohin.
  2. Unter Bot die Message Content Intent einschalten — ohne sie sieht der Bot keine Nachrichtentexte.
  3. Unter OAuth2 → URL Generator: Scope bot mit den Rechten View Channels, Read Message History, Send Messages, Add Reactions (für den Diktat-Kanal) sowie Connect und Use Voice Activity (für die spätere Aufnahme) — die erzeugte URL öffnen und den Bot auf euren Server einladen.
  4. Auf dem Server einen Kanal #diktat anlegen. Wer dort schreiben darf, darf diktieren.
